# dsh-doc-import

DSH Web 文档导入插件：拖入 / 粘贴 / 选择 txt · md · csv · docx · pdf，host 端解析并内容寻址
存储；扫描版 PDF 自动逐页 OCR；消息里只携带一行紧凑引用，聊天区渲染为**文件卡片**
（点击弹全文预览、可打开原始文件），模型用 `read_document` 按需回读全文。

安装、设置、开发与验证命令见仓库根 [`README.md`](../../README.md)；
协作规则与踩坑见 [`AGENTS.md`](../../AGENTS.md)；进度交接见 [`docs/PROGRESS.md`](../../docs/PROGRESS.md)。
